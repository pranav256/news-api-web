    HOW IT WORKS

    Serverless Architecture & Data Behaviors

    Reliable static JSON without running databases, server daemons, or billable infrastructure.

    PHASE 01

    Scheduled Scraper

    A GitHub Actions workflow triggers every two hours. It runs Python ingestion workers that query NewsAPI endpoints (within developer plan budget) and fallback RSS feeds for India, the US, and the UK.

    PHASE 02

    Atomic Persistence

    Incoming news items are deduplicated strictly by canonical URL. Writes are atomic; if an upstream feed fails, the workflow preserves the previous valid file so consumers never see truncated data.

    PHASE 03

    Global GitHub CDN

    Files are committed to GitHub only when contents change. GitHub’s global edge servers host the raw files with Access-Control-Allow-Origin: *, allowing direct in-browser fetch() anywhere.

    URL Deduplication No duplicate stories across multiple RSS sources or pagination windows.
    Graceful Retention Provider timeouts keep the last good file. Stale status is flagged in status.json.
    Zero API Keys You fetch public raw files; no credentials to rotate or leak on your frontend.
    Dual Output Shapes Choose between standard NewsAPI compatibility or enriched provider metadata.
